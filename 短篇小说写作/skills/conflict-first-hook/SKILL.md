# 冲突先行导语设计法

通过"先保证吸引力，再倒推合理性"的方式创作高吸引力导语。

## 核心理念

| 层级 | 职责 | 约束 |
|------|------|------|
| 冲突 | 吸引力 | 无，可以极端荒诞 |
| 动机 | 代入感 | 必须生活化、多人物参与 |
| 设定 | 逻辑自洽 | 无，奇幻/现实皆可 |

**底层逻辑**：把"吸引力"和"合理性"解耦，先锁定吸引力天花板，再用动机和设定往回圆。

## 流程

```
1. 确定方向/主题
       ↓
2. 设计3个极端冲突（只管吸引力，不管合理性）
       ↓
3. 筛选最佳冲突
       ↓
4. 配复杂动机（多人物、生活化）
       ↓
5. 找逻辑漏洞
       ↓
6. 添加设定修补（最多3轮）
       ↓
7. 组装成导语
```

## 各步骤要点

### 步骤2：设计极端冲突

**原则**：只管吸引力，不管合理性。问自己"读者看到这句话会不会停下来"。

**好冲突的特征**：
- 强烈反差（本该是X，实际是Y）
- 3秒内让人想问"为什么"
- 荒诞但不离谱

**输出**：3个备选冲突，各用1句话表达

### 步骤3：筛选冲突

**标准**：读者会不会在3秒内想知道"为什么会这样"

**淘汰信号**：
- 套路感强（"又是这种"）
- 反差不够极端
- 没有让人追问的欲望

### 步骤4：配复杂动机

**要求**：
- 不解释极端事件本身，而是解释"为什么这个家庭/关系会走到这一步"
- 必须多人物参与（主角、施害者、旁观者各有角色）
- 必须生活化（读者能理解的逻辑：贪钱、面子、控制欲、认知偏差等）

**动机模板**：
```
[主角的行为模式] + [施害者的行为模式] + [长期形成的关系闭环]
```

### 步骤5-6：找漏洞 + 补设定

**常见漏洞类型**：
| 类型 | 示例 |
|------|------|
| 跳跃断层 | 偏心→卖女儿，中间缺触发事件 |
| 角色缺席 | 动机里的关键人物在冲突里消失 |
| 状态矛盾 | 主角很优秀，为何没独立 |
| 逻辑打架 | 不重视她，又嫌卖便宜 |
| 违法认知 | 为什么觉得这样做没问题 |

**修补原则**：
- 优先用现实设定圆
- 现实圆不上，用奇幻设定兜底
- **奇幻设定可以用于任何层面**（冲突本身、揭露方式、反击手段），唯一标准是吸引力
- 不必担心"品类滑动"——如果奇幻元素让冲突更抓人，就用
- **最多补3轮**，圆不上就换冲突

**设定合并技巧**：多个漏洞可能指向同一个设定，先列出所有设定方案，再看哪些能合并。

## 适用边界

| 适合 | 不适合 |
|------|--------|
| 追求突破、创新 | 追求稳定、批量产出 |
| 创作者对吸引力有判断力 | 创作者经验不足 |
| 灵感枯竭需要激发 | 有明确素材库可用 |

**关于奇幻元素**：本流程不限制奇幻元素的使用范围。无论是纯现实、轻奇幻还是重奇幻，唯一判断标准是**吸引力**。品类滑动不是问题——如果奇幻设定让冲突更抓人，就用。

## 与现有流程的关系
