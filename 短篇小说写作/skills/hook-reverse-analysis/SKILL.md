# 导语逆向拆解框架 v5

基于「冲突先行导语设计法」对爆款导语进行结构化拆解。

## 核心理念

正向设计：方向 → 冲突 → 动机 → 设定 → 组装
逆向拆解：从成品倒推每一层的设计选择

## ⚠️ 多导语处理规范

**多个导语时，必须分开输出**：
- 每个导语单独生成一个拆解报告文件
- 文件命名：`[导语前5个字]导语拆解报告.md`
- 禁止合并成一个文件

**示例**：用户提供3个导语
- ✅ 输出3个文件：`从我记事起导语拆解报告.md`、`婚礼宴会上导语拆解报告.md`、`麻将桌上导语拆解报告.md`
- ❌ 不要合并成：`三篇导语拆解报告.md`

## 拆解流程

```
0. 方向层：题材方向 + 情绪内核 + 读者痛点
       ↓
1. 冲突层：提炼核心冲突 + 识别冲突模式
       ↓
2. 动机层：认知边界分析 → 还原人物动机 → 关系闭环
       ↓
3. 设定层：识别设定类型 + 漏洞修补方式
       ↓
4. 组装层：拆解结构 + 提炼技法
```

## 各层拆解要点

### 0. 方向层

**任务**：
- 识别题材方向（家庭、职场、情感、校园...）
- 提炼情绪内核（愤怒、心疼、爽、恐惧...）
- 定位目标读者痛点（什么人看了会有共鸣）
- 预判爽点类型（反击爽、逆袭爽、真相大白爽...）

**输出格式**：
```
题材方向：[XX题材]
情绪内核：[主要情绪1] + [次要情绪2]
读者痛点：[什么经历/身份的人会共鸣]
爽点预期：[读者期待什么样的爽]
```

### 1. 冲突层

**任务**：
- 用一句话提炼核心冲突
- 识别使用了哪些冲突模式
- 对核心冲突进行吸引力检测

---

#### ⚠️ 核心冲突的定义（重要）

核心冲突 ≠ 情节概括。核心冲突是**冲突本质的提炼**，必须能脱离具体设定独立存在。

**抽象层级**：核心冲突可以有多个抽象层级，**必须提炼到最抽象层**：

| 层级 | 说明 | 示例（假话成真卡） |
|------|------|-------------------|
| ❌ 情节概括 | 描述发生了什么 | 主角获得假话成真卡后让渣男的谎言都变成现实 |
| ⚠️ 具体层 | 保留人物关系 | 原配让渣男的谎言反噬他自己 |
| ✅ 抽象层 | 只保留行为本质 | **说谎者被自己的谎言反噬** |

---

#### ⚠️ "具体设定"的定义（必须剥离）

以下内容都属于"具体设定"，必须在核心冲突中剥离：

| 类别 | 示例 | 说明 |
|------|------|------|
| 奇幻元素 | 系统、金手指、假话成真卡、死后视角 | 全部删除 |
| 具体场景 | 麻将桌、豪宅、公司、婚礼 | 全部删除 |
| 具体物件 | 手镯、安眠药、转账记录 | 全部删除 |
| 具体人物关系 | 丈夫/妻子、男友/女友、婆婆/儿媳 | 抽象为角色功能（见下表） |

**人物关系抽象规则**：

| 具体关系 | 抽象为 | 说明 |
|----------|--------|------|
| 丈夫/妻子 | 保护者/被保护者 | 或"承诺者/被承诺者" |
| 男友/女友 | 关系中的两方 | 视情况选择更准确的角色功能 |
| 婆婆/儿媳 | 权力方/弱势方 | 或"评判者/被评判者" |
| 父母/孩子 | **可保留** | 因为"父母-孩子"关系张力强且普适 |
| 老板/员工 | 权力方/弱势方 | 视情况选择 |

---

#### 更多示例（含演进过程）

**示例1：装穷父母导语**
```
❌ 情节概括：孩子为穷父母去死，死后发现父母是富人
⚠️ 中等抽象：孩子为父母牺牲，发现父母骗了自己
✅ 高度抽象：父母用谎言骗孩子，孩子为父母牺牲自己
```

**示例2：女兄弟/系统文导语**
```
❌ 情节概括：女友容忍男友和女兄弟的越界行为，因为有系统能收割
⚠️ 中等抽象：看似被绑的猎物，实则是来收割的猎人
✅ 高度抽象：猎物以为自己是猎人（9字）
```

**示例3：麻将桌/雀神宝宝导语**
```
❌ 情节概括：丈夫在麻将桌上当众出卖妻子尊严给小三
⚠️ 中等抽象：丈夫当众出卖妻子尊严给外人
✅ 高度抽象：保护者帮外人羞辱被保护者（12字）
```

**示例4：末日地堡导语**
```
❌ 情节概括：主角为给父母省粮自杀，死后发现父母编造末日囚禁她18年
✅ 高度抽象：父母编造谎言囚禁孩子，孩子为"救"父母自我牺牲
```

---

#### 提炼方法

1. 剥离具体设定（按上表逐项检查）
2. 抽象人物关系为角色功能
3. 用"A对B做了X，B却为A做了Y"或类似简洁格式检验
4. **目标：提炼到最抽象层，让冲突能迁移到其他题材**

---

#### ⚠️ 强制自检（必须执行）

提炼完核心冲突后，必须执行以下自检：

| 自检项 | 问题 | 处理 |
|--------|------|------|
| 设定剥离 | 还包含奇幻元素/具体场景/具体物件吗？ | 如有，删除 |
| 关系抽象 | 还包含具体人物关系吗？（丈夫/妻子等） | 抽象为角色功能 |
| 继续抽象 | 还能再抽象一层吗？ | 尝试提炼，对比选择 |
| 迁移检验 | **这句话能套用到3个以上不同题材吗？** | 如不能，继续抽象 |
| 张力保留 | 抽象后是否失去关系张力？ | 如失去太多，退回上一层级 |
| 长度检验 | 超过15个字了吗？ | 如超过，继续精简 |

**自检示例**：
```
初稿："丈夫在麻将桌上当众出卖妻子尊严给小三"

自检：
- 设定剥离：包含"麻将桌" → 删除 → "丈夫当众出卖妻子尊严给小三"
- 关系抽象："丈夫/妻子"→"保护者/被保护者"，"小三"→"外人"
  → "保护者当众出卖被保护者尊严给外人"
- 继续抽象：可简化为"保护者帮外人羞辱被保护者"
- 迁移检验：父母帮外人羞辱孩子✓ 老板帮客户羞辱员工✓ 朋友帮对手羞辱你✓ → 通过
- 张力保留："保护者-被保护者"保留了核心张力
- 长度检验：12字 ✓

终稿："保护者帮外人羞辱被保护者"
```

---

#### 冲突模式速查

| 模式 | 核心 | 识别信号 |
|------|------|----------|
| 反差模式 | 本该是X，实际是Y | 身份/结果/对象/态度/价值的落差 |
| 极端化模式 | 小事→极端后果 | 不合理的数字、时间、后果 |
| 错位模式 | 认知/情感/身份错位 | 受害者不知道、反应不正常、角色行为不符 |
| 量化模式 | 用数字制造冲击 | 具体金额、次数、时间 |
| 日常恐怖化 | 日常场景→生死情境 | 普通场景突然变危险 |
| 信息差模式 | 谁知道/谁不知道 | 偷听、揭示、隐藏信息 |

---

#### ⚠️ 吸引力检测的边界（重要）

吸引力检测只看"核心冲突那一句话"本身，不能把导语的设定、画面、包装混入检测。

| 检测项 | 检测对象 | 常见错误 |
|--------|----------|----------|
| 3秒内让人想问"为什么" | 核心冲突本身 | 把整个导语的悬念混入 |
| 强烈反差 | 核心冲突中的反差 | 把设定包装的新颖性算进去 |
| 不会说"又是这种" | 核心冲突的新颖度 | 把奇幻设定的新颖性算进去 |
| 能用1句话表达 | 核心冲突的简洁度 | — |
| 有画面感 | 核心冲突本身是否有具体视觉元素 | 把导语中的场景描写算进去 |

**如果核心冲突本身通不过某项检测**：说明这篇导语的吸引力来自其他层（设定层/组装层），而非冲突层本身。这是重要发现，应在报告中标注。

---

#### 输出格式

```
核心冲突：[一句话，≤15字，脱离具体设定]

自检记录：
- 初稿：[...]
- 设定剥离：[删了什么]
- 关系抽象：[什么关系→什么角色功能]
- 继续抽象：[尝试了什么/为何选择当前版本]
- 迁移检验：[能套用到哪些不同题材]
- 终稿：[...]

使用模式：
| 模式 | 应用 |
|------|------|
| XX | XX |

吸引力检测（仅针对核心冲突本身）：
- [ ] 3秒内让人想问"为什么"
- [ ] 强烈反差
- [ ] 不会说"又是这种"
- [ ] 能用1句话表达
- [ ] 有画面感

吸引力来源判断：[主要来自冲突层/设定层/组装层]
```

### 2. 动机层

**任务**：
1. **先做认知边界分析**（谁知道什么/不知道什么）
2. 基于认知边界，还原每个角色的行为模式和内核
3. 识别主角困境类型
4. 画出关系闭环（如有）
5. **执行理解自检**

---

#### ⚠️ 认知边界分析（必须先做）

**为什么重要**：只有先搞清楚"谁知道什么"，才能正确判断"谁骗了谁"、"谁是帮凶"、"谁是受害者"。

**分析表格**：

| 角色 | 知道什么 | 不知道什么 | 信息来源 |
|------|----------|------------|----------|
| [角色A] | [列出] | [列出] | [怎么知道的/为什么不知道] |
| [角色B] | [列出] | [列出] | [怎么知道的/为什么不知道] |

**关键问题**：
- 这个角色的信息是从哪里获得的？
- 有没有角色故意隐瞒信息？证据是什么？
- 有没有角色被错误信息误导？谁给的错误信息？

---

#### 动机分析

**施害者动机速查**：利益驱动、控制欲、认知扭曲、情感扭曲、面子工程

**主角困境速查**：懂事陷阱、付出陷阱、沉默陷阱、证明陷阱、信息差、认知茧房、经济依附、孤立无援、情感绑架、身份困境

**输出格式**：
```
| 角色 | 行为模式 | 生活化内核 |
|------|----------|------------|
| XX | XX | XX |

关系闭环：[如有则画出]

代入感来源：[读者能共情的点]
```

---

#### ⚠️ 理解自检（必须执行）

完成动机分析后，必须执行以下自检：

| 自检项 | 问题 | 处理 |
|--------|------|------|
| 文本证据 | 我的理解有文本证据支持吗？ | 如无明确证据，标注为"推测" |
| 奥卡姆剃刀 | 有没有更简单的解释？ | 优先选择更简单的解释，除非文本明确否定 |
| 反应匹配 | 如果我的理解对，角色应该有什么反应？实际反应匹配吗？ | 如不匹配，重新检视理解 |

**⚠️ 过度解读警告**：如果文本没有明确暗示某个角色"故意隐瞒/欺骗"，不要假设存在欺骗关系。警惕往复杂方向过度解读。

**自检示例**（以"绿茶妈妈"导语为例）：
```
错误理解：妈妈知道表妹还活着 → 故意骗女儿 → 女儿是被利用的帮凶

自检：
- 文本证据：没有任何文本说明妈妈知道表妹还活着
- 奥卡姆剃刀："母女都被错误信息骗了"比"妈妈骗女儿"更简单
- 反应匹配：如果妈妈在骗女儿，女儿发现真相后应该愤怒"你连我也骗"；
  但实际反应是困惑"这怎么可能"→ 说明女儿也不知道，不是被妈妈骗

修正理解：母女都以为表妹死了 → 谎言被"死人"亲手拆穿
```

---

### 3. 设定层

**任务**：
- 识别现实设定/奇幻设定
- 还原"漏洞→修补"的对应关系

**常见漏洞类型**：
- 跳跃断层（缺触发事件）
- 角色缺席
- 状态矛盾
- 逻辑打架
- 违法认知

**输出格式**：
```
设定类型：[纯现实/轻奇幻/重奇幻]

| 漏洞 | 修补 |
|------|------|
| XX | XX |

设定作用：[设定服务于什么]
```

### 4. 组装层

**任务**：
- 画出结构图（钩子→压迫→揭示→结尾）
- 提炼关键技法

**结构图格式**：
```
[第一步] → 描述
      ↓
[第二步] → 描述
      ↓
...
```

**常见技法清单**：

| 类别 | 技法 |
|------|------|
| 开场 | 钩子句开场、日常场景开场、标签先行 |
| 压迫 | 递进压迫、三段并列、沉默比说话狠 |
| 揭示 | 偷听、延迟揭示、双重反转 |
| 数字 | 量化痛苦、数字对称、价格标签 |
| 体感 | 身体反应代替情绪标签、具体物件 |
| 结尾 | 暗示反击、明确反击、悬念、毁灭式 |
| 话术 | 讽刺命名、PUA话术还原、金句收尾 |

**输出格式**：
```
结构：[结构图]

关键技法：
| 技法 | 具体运用 |
|------|----------|
| XX | XX |
```

## 输出要求

**拆解完成后**：
- 输出格式：.md文件
- 文件命名：`[导语前5个字]导语拆解报告.md`
- **多个导语时，每个导语单独一个文件**
- 示例：导语开头是"婚礼宴会上，当许墨川把我带到..."，则文件名为`婚礼宴会上导语拆解报告.md`
