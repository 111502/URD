# 导语逻辑检查工具

## 核心理念

导语的任务是**制造冲击、留下悬念、让人想看下去**。

导语不是完整故事，不需要回答所有问题。某些"为什么"恰恰是吸引读者继续读的钩子。

因此，检查导语逻辑的标准与检查完整故事不同。

## 检查标准（仅两条）

### 1. 主角行为逻辑是否成立？

读者需要能代入主角。检查：

- 基于主角被告知的信息和所处的环境，他的行为是否合理？
- 主角的动机链条是否完整？（相信X → 因此感到Y → 所以做了Z）

**注意**：主角被欺骗是可以的，主角的信息是假的也可以。只要"在他所知的范围内"行为合理即可。

### 2. 有没有细节让读者在导语阶段就出戏？

出戏的原因通常是：

| 类型 | 表现 | 举例 |
|------|------|------|
| **信息过载** | 塞入了本该留给正文的背景 | 一句台词解释了18年的来龙去脉 |
| **常识冲突** | 细节与读者的常识矛盾 | "等器官成熟"但读者知道器官不需要等18年 |
| **因果断裂** | 关键元素没有来源 | 罐头从哪来？她怎么18年没发现？ |
| **逻辑追问** | 读者会停下来想"等等，这不对" | 有钱为什么不早要赎金？ |

**关键区分**：
- **悬念**：读者想知道答案，但愿意继续读下去找答案（"他们为什么这么做？"）
- **困惑**：读者卡在这里，无法继续（"这说不通啊"）

导语可以留悬念，不能制造困惑。

## 执行流程

### 第一步：识别导语的吸引力

在检查逻辑之前，先明确这个导语的核心吸引力是什么：

- 什么是核心反转？
- 什么制造了情绪冲击？
- 什么让读者想继续看？

**这些元素在修改时必须保护。**

### 第二步：检查主角行为逻辑

逐一审视主角的关键行为：

- 他做了什么？
- 他为什么这么做？（基于他所知的信息）
- 这个"为什么"在文中有没有体现？

如果行为逻辑不成立，标记为问题。

### 第三步：扫描出戏细节

逐句阅读，模拟普通读者的心理：

- 读到这里会不会停下来追问？
- 这个细节是"想知道更多"还是"这不对劲"？
- 有没有信息过载（一句话塞太多背景）？
- 有没有常识冲突？

标记所有让读者可能出戏的点。

### 第四步：区分问题严重程度

| 严重程度 | 定义 | 处理方式 |
|----------|------|----------|
| **致命** | 主角行为逻辑不成立 | 必须修改 |
| **较重** | 读者会卡住、无法继续 | 应该修改 |
| **较轻** | 读者可能闪过疑问但不影响继续阅读 | 可以修改 |
| **不是问题** | 悬念而非困惑 | 保留 |

### 第五步：提出修改建议

修改原则：

1. **最小改动原则**：能改一句话解决的，不改整段
2. **保护吸引力**：核心反转、情绪冲击点不能动
3. **删繁就简**：信息过载的解决方案通常是删减，而非补充
4. **模糊化处理**：有些细节不需要解释清楚，模糊掉读者就不会追问

修改手法：

| 问题类型 | 常用修改手法 |
|----------|--------------|
| 信息过载 | 删减细节，只保留核心反转需要的信息 |
| 常识冲突 | 换一个说法，绕开读者的常识 |
| 因果断裂 | 加一句简短的铺垫，或模糊化处理 |
| 逻辑追问 | 删掉引发追问的细节，或改写为不引发追问的表述 |

## 输出格式

```
## 导语吸引力分析
[列出核心反转、情绪冲击点、悬念钩子]

## 逻辑检查结果

### 主角行为逻辑
[成立/不成立，简要说明]

### 出戏细节
[逐条列出，标注严重程度]

## 修改建议

### [问题1]
- 原文：...
- 问题：...
- 建议：...
- 修改后：...

### [问题2]
...

## 修改后版本（可选）
[如果改动较多，提供完整的修改后版本]
```

## 注意事项

- 不要用检查完整故事的标准来检查导语
- 反派/配角的动机空白通常是悬念，不是问题
- 主角的动机空白才是问题
- 修改建议必须具体，给出修改后的文字
- 始终把"保持吸引力"放在"修补逻辑"之前
