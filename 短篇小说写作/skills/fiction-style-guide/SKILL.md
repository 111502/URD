# 小说创作写作规范：去AI味 v1

## 核心理念

**AI味的本质是：不信任读者。**

所有AI味的毛病——解释情绪、点明悬念、总结意图、铺垫氛围——背后都是同一个冲动：怕读者看不懂、感受不到、错过重点。

### 四条根本原则

**原则一：读者不傻**

不需要写"她的声音柔弱，表情无辜，眼眶里还含着泪水"来证明她在装。只需要写"她的声音柔弱，表情无辜"，然后"可我清清楚楚地看到，她在笑"——读者自己会懂。

**原则二：情绪不说破**

不写"心里涌起一股暖意"、"鼻子一酸"。如果前面的情节和对话写到位了，读者自己会感动。写出来反而减分。

**原则三：少即是多**

能删就删。删完读一遍，如果意思还在、节奏没断，就说明原来那些字是废话。

**原则四：作者隐身**

作者不能跳出来当旁白。不总结、不提问、不预告。

---

## 红线清单：绝对不要

### 1. 情绪标签

直接说出角色的感受，而不是让读者从情节中体会。

**禁用词：**
- "心中涌起一股暖意"
- "眼眶微微泛红"
- "鼻子一酸"
- "心里一阵发凉"
- "心跳加速"
- "浑身发冷"
- "内心掀起惊涛骇浪"

| 反例 | 正例 |
|------|------|
| 他犹豫了一下，低下头，眼眶微微泛红。 | 他犹豫了一下。 |
| 我看着他认真的眼神，心里涌起一股暖意。点了点头。 | 我看着他认真的眼神，点了点头。 |
| 她感到深深的悲伤涌上心头。 | 她把烟摁灭，又点了一根。 |

### 2. 作者旁白

作者跳出来替读者总结、预告、提问、强调。

**四种类型：**
- 总结句："他们越闹，反噬就越狠"
- 预告句："是时候用那个秘密反击了"
- 提问句："是陷阱还是转机？"
- 强调句："只有我能听见这句话"

| 反例 | 正例 |
|------|------|
| 萱萱的秘密让我看到了翻盘的希望。而这个陌生人的出现，是陷阱还是转机？ | （删除，停在短信内容） |
| 她把我塑造成了施暴者，而她是那个劝架的无辜妹妹。 | （删除，前文已呈现） |
| 萱萱凑到我耳边说了一句话。只有我能听见。 | 萱萱凑到我耳边说了一句话。 |

### 3. 装饰性动作

对情节没有推动作用的小动作，通常是影视剧里用滥的。

**常见废动作：**
- "摘下眼镜揉了揉眉心"
- "喉结上下滚动"
- "脖子上的青筋鼓起来"
- "用手背擦了擦眼睛"
- "攥紧衣角"
- "下意识攥紧了拳头"

| 反例 | 正例 |
|------|------|
| 王医生听完，摘下眼镜揉了揉眉心，长长叹了口气。 | 王医生听完，长长叹了口气。 |
| 他愣了几秒，眼眶更红了，嘴唇哆嗦着，喉结上下滚动。 | 他愣了几秒，嘴唇哆嗦着。 |

### 4. 陈腐比喻

用了几百年的比喻，一看就是AI在"努力表现得很文学"。

**禁用：**
- "每一个字都是我的血泪"
- "这句话刺进我心里"
- "像是一夜之间老了十岁"
- "她的笑容如阳光般温暖"
- "他的目光像刀子一样锐利"

| 反例 | 正例 |
|------|------|
| 她的笑容如阳光般温暖。 | 她一笑，眼角挤出三道褶子。 |
| 他的目光像刀子一样锐利。 | 他盯着她看，看得她发毛。 |

### 5. 过度铺垫

与情节无关的环境描写、氛围营造。

| 反例 | 正例 |
|------|------|
| 初秋的傍晚，风吹在身上很舒服。夕阳西下，天边一片橙红色，把湖面染成金色。 | （删除，或只保留一句） |
| 脑海里的画面开始翻涌，从小到大那些我以为早就忘记的事情一幕幕浮现。 | 从小到大那些我以为早已忘记的事情一幕幕浮现。 |

### 6. 冗余修饰

**副词堆砌：**
- "不耐烦地"、"悻悻地"、"踉踉跄跄地"
- "清清楚楚地"、"明晃晃的"

**连接词滥用：**
- "一时间"、"忽然之间"
- "然而"、"但是"连用

| 反例 | 正例 |
|------|------|
| 我捂着脸，眼眶发酸，却一滴泪都流不出来。 | 我捂着脸，眼眶发酸。 |
| 然而，她没有说话。但是，她的眼神变了。 | 她没说话，眼神变了。 |

## 替代策略：怎么写

### 1. 对话口语化

| 反例 | 正例 |
|------|------|
| 因为你让我看到了我妹妹如果活着可能的样子。 | 我老想，我妹要是还在，可能也跟你一样。 |
| 保守治疗的话……最多三个月。 | 保守治疗的话……不到三个月。 |
| 又不是什么绝症，先保守治疗。 | 又不是没救，先拖拖看。 |
| 我认为我们应该重新考虑这个决定。 | 要不……再想想？ |

### 2. 钩子靠悬置，不靠提问

好的钩子让读者自己产生疑问，而不是作者替读者问出来。

| 反例 | 正例 |
|------|------|
| ……这个陌生人的出现，是陷阱还是转机？ | （停在"你方便见一面吗？"） |
| 妈妈的语气比我印象中任何时候都要阴冷："林知夏，你敢报警？你等着。" | "林知夏，你敢报警？你等着。" |

**有效钩子的形式：**
- 未完成的动作
- 悬置的信息
- 突然出现的变量
- 一句没有回应的话

### 3. 用动作代替情绪

| 情绪 | 反例 | 正例 |
|------|------|------|
| 愤怒 | 他非常愤怒。 | 他把碗摔了。 |
| 恐惧 | 她内心充满恐惧。 | 她手抖得按不准电梯按钮。 |
| 紧张 | 她紧张得心跳加速。 | 她一直在摸自己的耳垂。 |
| 惊讶 | 他惊讶地瞪大了眼睛。 | 他嘴里的烟差点掉下来。 |
| 走神 | 他陷入了沉思。 | 他盯着窗外看了半天，其实什么也没看。 |

### 4. 保持节奏变化

句子长度、段落长度要有变化。紧张场景用短句，舒缓场景可以慢下来。

## 自查表

写完初稿后逐条检查：

### 一、情绪标签
- [ ] Ctrl+F搜索："涌起"、"一酸"、"发酸"、"心想"、"忽然觉得"
- [ ] 删掉后情绪还能从情节中感受到吗？如果能，删。

### 二、作者旁白（重点检查章节结尾）
- [ ] 是否有总结句？
- [ ] 是否有预告句？
- [ ] 是否有替读者提问？
- [ ] 是否有强调句？

### 三、动作描写
- [ ] 是否有装饰性小动作？
- [ ] 删掉后信息是否完整？如果完整，删。

### 四、对话
- [ ] 随机挑三段对话读出声，像不像人说话？
- [ ] 有没有书面腔？能不能更短、更口语？

### 五、结构
- [ ] 单独看每章最后两段，有没有总结/预告/提问？
- [ ] 钩子是靠"悬置的信息"还是靠"作者提问"？
- [ ] 最后一句能不能更短、更硬？

## 快速扫描法

时间紧时，至少做这三步：

1. **Ctrl+F搜索**："涌起"、"一酸"、"发酸"、"心想"、"忽然觉得"、"清清楚楚"
2. **单独看每章最后两段**：有没有总结/预告/提问
3. **随机挑三段对话读出声**：像不像人说话
