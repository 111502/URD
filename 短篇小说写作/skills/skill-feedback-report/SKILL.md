# 技能反馈报告生成器 v1

当用户反馈某个skill效果不佳时，生成结构化报告以便另一个对话优化该skill。

## 报告生成流程

### 1. 收集信息

向用户确认以下信息（如对话中已有则跳过询问）：

- 技能名称
- 原始任务/用户意图
- 实际输出结果
- 期望的正确结果

### 2. 生成报告

使用以下模板生成markdown报告：

```markdown
# Skill反馈报告：[技能名称]

## 基本信息
- **技能名称**：
- **使用日期**：
- **问题严重程度**：[致命/严重/一般/轻微]

## 问题诊断

### 任务描述
[用户想要完成什么任务]

### 实际表现
[skill实际输出了什么，或做了什么]

### 期望表现
[正确的输出应该是什么样的]

### 差距分析
[实际与期望之间的具体差异]

## 失败案例

### 案例1
- **输入**：[触发skill的具体输入]
- **实际输出**：[skill给出的输出]
- **期望输出**：[正确输出应该是什么]
- **问题定位**：[哪个环节出了问题]

（如有多个案例，继续添加）

## 根因分析

### 可能的问题原因
1. [原因1：如触发条件不准确]
2. [原因2：如流程步骤遗漏]
3. [原因3：如输出格式错误]

### 问题类型判断
- [ ] 触发条件问题（该触发没触发/不该触发却触发了）
- [ ] 流程逻辑问题（步骤顺序错误/缺少步骤）
- [ ] 输出质量问题（格式/内容/风格不符合预期）
- [ ] 边界情况问题（特殊情况未处理）
- [ ] 其他：

## 优化建议

### 建议修改点
1. [具体建议1]
2. [具体建议2]

### 补充说明
[任何有助于优化的额外上下文]
```

## 输出要求

1. 报告必须基于对话中的**真实案例**，不要臆造
2. 问题描述要**具体**，避免模糊表述如"效果不好"
3. 如信息不足，先向用户补充询问
4. 生成.md文件供用户下载和传递
